# Airbus Beluga Cargo Visualiser

**A school project showing how the Beluga carries huge cargo.**
Open `index.html` in a browser. (My earlier Beluga project is [beluga-diagram](https://github.com/TechTonicCortex/beluga-diagram).)

## Three tabs
1. **Size comparison**: how big the Beluga is next to other things
2. **Loading animation**: how cargo gets loaded
3. **What fits**: which items fit inside

## How it works
Plain HTML, CSS and JavaScript with shapes drawn in code. No external images.

## Fact-checking note
I checked my facts before presenting. Numbers for aircraft vary by version, so I give them as approximate and name the model.

## What I learned
My first drawing looked bad, so I switched to an interactive visualiser that explains better.
